# AetherFire — Undie Revamp Canon Baseline v0.1

> **Status:** CURRENT CANON — user-authorized revamp baseline  
> **Date:** 2026-10-05  
> **Scope:** Undie system revamp, its professional/economic/political interfaces, Undi visual philosophy, and the handoff boundary for MC2 pathway design.  
> **Authority boundary:** This file records only the eight user-authorized decisions below. It does **not** canonize implementation proposals that have not been explicitly accepted.  
> **Excluded design source:** `AetherFire_Undie_Revamp_Proposal_Total_War_Transition_v0.1.md` is not part of this revamp baseline and must not be used as philosophy, fallback, bridge, or reconstruction anchor.

---

## 0. Core replacement

The current Undie revamp replaces the prior ontology in which Undie was treated as a Slave class / humiliation-centered subsystem.

```text
OLD:
Slave umbrella
→ Undie class
→ sex-work-centered implementation
→ intentional humiliation
→ resistance / surveillance / political manipulation

SUPERSEDED
```

The new baseline begins from a professional ecosystem and allows politics, corruption, scandal, gray-market activity, security conflict, and foreign-policy consequences to emerge from that ecosystem rather than defining its reason for existence.

```text
NEW:
professional ecosystem
→ multiple professional branches
→ mobility / markets / access / institutions
→ gray-zone interaction
→ political exploitation / scandal / conflict where applicable
```

`Undie != Slave class`.

`Undie != sex work`.

`Undie != punishment`.

`Undie != intentional humiliation regime`.

# 1. Undie returns to its original professional foundation

## CURRENT CANON

Undie is restored toward its original design foundation:

- a stigmatized profession / professional ecosystem;
- socially controversial or morally disputed in some contexts;
- capable of professional specialization, prestige, income, community, organization, and occupational identity;
- not created primarily as a state humiliation mechanism.

Sex work is only one possible branch inside the wider Undie ecosystem.

```text
SEX WORK
IS_A possible Undie branch

SEX WORK
!= definition of Undie
!= mandatory center of Undie
```

Political corruption, scandal, coercion, patronage, intelligence interest, or factional struggle may exploit the Undie ecosystem, but those political uses are no longer the primary reason the ecosystem exists.

## SUPERSEDED

- `Undie = Slave class`.
- `Undie = any slave who performs prostitution`.
- state-designed humiliation as the defining purpose of Undie.
- deliberate creation of humiliation primarily to manufacture obedience/resistance polarization.

## OPEN

The exact legal ontology of Undie remains unresolved. This file does not yet decide whether the state formally treats Undie through licensing, professional registration, occupational law, guild-like structures, or another legal form.

# 2. Undie is again a complete professional system; Slave core is removed

## CURRENT CANON

Undie is a complete professional ecosystem rather than a single job.

The ecosystem may contain, where later specified:

- training;
- professional standards;
- occupational specialization;
- organizations or intermediaries;
- reputation and market relations;
- mobility and booking/dispatch interfaces;
- professional community;
- economic activity;
- safety and regulation;
- interaction with public institutions.

The old shared Slave core is removed from the Undie architecture.

```text
Undie
X→ BELONGS_TO Slave umbrella

Undie
X→ IS_A Slave class
```

Any old rule whose only justification was Undie's membership in the Slave system must be re-evaluated rather than carried over automatically.

## MC2 DIRECTION — CURRENT CANON

MC2 will be rewritten away from a degradation/slave-entry pathway.

Her new design direction is:

```text
need to approach / investigate / reach the maternal-side political pathway
→ need access to a politically useful gray-zone environment
→ Undie ecosystem can become one access environment
→ political pathway develops from there
```

Undie is no longer a place MC2 simply "falls into" as punishment or loss of status.

The exact route, profession, cover, affiliation, intermediary, actor, or incident that brings MC2 into this environment is not established by this file.

# 3. Professional mobility is restored and broadened beyond sex work

## CURRENT CANON

Undie professionals are not inherently tied to one district, brothel, facility, or fixed workplace.

The ecosystem is mobile and may operate through:

- venues;
- events;
- private residences;
- private bookings;
- temporary assignments;
- performances;
- hospitality contexts;
- other authorized or gray-zone environments.

The occupational range is broader than sex work.

The current accepted direction includes multiple kinds of entertainment, performance, companionship, hosting, artistic, and adjacent gray-zone professions.

Examples discussed by the author include:

- dancers;
- singers;
- private ouran-like hosting;
- private geisha-like services;
- courtesan-like roles based on art/skill without necessarily selling sex;
- other related activities.

These examples establish the **breadth direction**, not yet a final exhaustive branch taxonomy.

## INVARIANT

```text
shared Undie ecosystem
!= same job
!= same service
!= same consent model
!= same intimacy level
!= same legal risk
```

# 4. Economic rebuild: cash + Credits; old Undie credit web is retired

## CURRENT CANON

The current tangled Undie-specific credit architecture is retired as a baseline.

The economic foundation becomes:

```text
CASH
= basic money

CREDITS
= state-backed electronic money
```

Credits are money, not a performance score, rank score, contribution metric, or automatic occupational progression variable.

## SUPERSEDED AS CURRENT UNDIE BASELINE

- Undie-specific `Credit Score` as progression/eligibility architecture;
- `Contribution Points` as a required Undie economic axis;
- the current Undie-specific `Credit Line` architecture based on status collateral;
- automatic reuse of the old multi-variable credit web.

These names or functions may only return later through a separate explicit decision.

## CREDIT / LENDING — UNDER CONSIDERATION

Credit, lending, advances, sponsorship, or comparable financial arrangements may exist, but they must be rebuilt carefully and cannot inherit the old Undie debt architecture automatically.

## DEBT ENFORCEMENT — CURRENT DESIGN CONSTRAINT

Debt enforcement / leverage may still exist.

It must not default to:

```text
debt
→ sexual service
→ ownership-like assignment
```

Instead, any debt mechanism must expose a traceable favor, concession, obligation, service, access cost, or other trade-off appropriate to the actual relation.

The exact favor system, collateral rules, enforcement authority, remedies, limits, and abuse controls remain OPEN.

# 6. Most brutality is removed; death handling, opposition, resistance-security interfaces are retained in revised form

## CURRENT CANON

The revamp removes most of the old brutality whose primary role came from the Slave/humiliation architecture.

This does not mean all danger, exploitation, violence, coercion, corruption, or institutional failure disappears.

The following functions are explicitly retained for redesign:

### Death handling

Death handling remains a relevant subsystem.

Its exact procedure, responsibility, compensation, investigation, evidence handling, family interface, cover-up potential, and jurisdiction are not yet fixed.

### Opposition

An opposition institution or opposition function exists within the design space and will be rebuilt.

This decision does not automatically restore the old Temple, Purple committee, or any previous organization unchanged.

### Undie / resistance / security interface

A portion of the old connection between Undie, resistance, and the security apparatus is restored.

However, the state/security response is no longer assumed to be one unified machine.

Different ministries, police forces, security bodies, local authorities, military-linked bodies, or other competent institutions may:

- receive different information;
- interpret the same incident differently;
- possess different jurisdiction;
- issue incompatible orders;
- intervene independently;
- interfere with each other;
- escalate an incident through coordination failure.

The desired system must be capable of incidents analogous in structure to multiple law-enforcement bodies converging on the same event and producing friendly-fire / code-blue-style confusion.

This analogy defines a **failure architecture**, not a requirement to copy United States police institutions or to canonize a specific historical event.

## INVARIANT

```text
multiple state/security actors
!= one unified actor
```

No particular agency list, command chain, or canonical friendly-fire incident is created by this file.

# 7. Undie returns to diplomacy and statecraft primarily through scandal, access, and vice/entertainment politics

## CURRENT CANON

Undie may again reach the level of diplomacy and statecraft.

The primary restored political functions are not Slave diplomacy or intentional state humiliation, but the political consequences of:

- entertainment / vice economies;
- elite or private access;
- political games;
- setups and compromising situations;
- performances or sensitive social situations;
- intimate relationships where applicable;
- exploitation of access;
- scandal;
- patronage;
- leverage.

These mechanisms may occur in both AetherFire and Transfusion EasterFire.

They do not imply that all Undie professionals are spies, political operators, sex workers, or intelligence assets.

```text
professional activity
+ access
+ money / reputation / private environments
→ may create political opportunity
```

Political exploitation is an emergent use of the ecosystem, not its universal job description.

## TE DIRECTION — DEFERRED IMPLEMENTATION

Transfusion EasterFire is intended to be redesigned later as a major commercial state focused strongly on tourism and experience economy, drawing broad design inspiration from:

- Las Vegas;
- Dubai;
- high-end resort economies around the world.

This direction is recorded, but TE's institutions, economy, law, professional structure, and exact relation to Undie are deferred to a later dedicated revamp.

# 8. Undi loses explicit visual humiliation; disputed Hoa Nguyệt appropriation remains

## CURRENT CANON

The explicit visual-humiliation function of Undi is removed.

Undi is no longer designed to make humiliation publicly obvious or to make the wearer visibly read as degraded.

The old design logic in which Undi openly converted Hoa Nguyệt visual language into a humiliating public marker is superseded.

## RETAINED DESIGN PHILOSOPHY — REVISED

AetherFire intentionally appropriated / copied ideas from Hoa Nguyệt national dress when developing Undi.

However, that intent is not provable from the evidence available to outside actors.

Therefore the political structure becomes:

```text
actual AF intent:
deliberate borrowing / appropriation

external evidence:
insufficient to prove intent conclusively

result:
diplomatic grievance
+ plausible deniability
+ argument over interpretation
```

The diplomatic weight remains, but it is no longer obvious or mechanically self-proving from the visual alone.

## INVARIANT

```text
visual similarity / suspicious genealogy
!= publicly proven hostile intent
```

Undi may therefore carry foreign-policy consequences without functioning as an explicit visual declaration of humiliation.
